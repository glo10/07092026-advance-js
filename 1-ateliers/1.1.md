# Atelier 1.1 : le mot clé this

## Préparation environnement de travail

1. Créez un nouveau dossier nommé atelier-1.1
2. Ouvrez votre éditeur de code sur ce dossier et ouvrez un terminal pour exécuter la commande suivante
```bash
npm init -y
```
3. Installez le module vitest à l'aide de la commande suivante à exécuter toujours depuis le même terminal
```bash
npm i -D vitest
```
4. Dans le fichier package.json de votre projet, remplacez les lignes suivantes :
```bash
# avant
  "scripts": {
    "test": "echo \"Error: no test specified\" && exit 1"
  }
# à remplacer par
  "scripts": {
    "test": "vitest"
  }
```
5. Récupérez ces sources contenant des tests unitaires qui ont été rédigés et placez le dossier tests/ et le fichier vitest.config.js à la racine de votre projet
6. Exécutez les tests à l'aide de la commande suivante, normalement tout est rouge

---

## Enoncé

7. L'objectif de l'exercice est d'appeler les différentes fonctions correctemet depuis la zone dédié dans chaque test permettant de faire passer la fonction du rouge au vert.
Pour cela, vous devez utiliser correctement le mot-clé this, les closures et les fonctions call(), apply() et bind() dans les appels.
**Attention, certaines fonctions doivent être modifier pour que le test passe**

---

## Bonus

8. Une fois que tout vos tests sont au vert, refactorisez votre code pour l'améliorer tout en gardant vos tests au vert.
