# Atelier 1.1 : le mot clé this

## Préparation environnement de travail

1. Créez un nouveau dossier nommé atelier-1.1

2. Récupérez ces sources contenant des tests unitaires et les fichiers sources depuis cette [ressource zippée](./resources/1.1.zip)

3. Exécutez les tests à l'aide de la commande suivante, normalement tout est rouge
```bash
npm run test
```
PS: pour isoler un test et l'exécuter tout seul ajouter .only à la ligne de teste concernée tels que `test()` devienne `test.only()`

---

## Enoncé

4. L'objectif de l'exercice est d'appeler les différentes fonctions correctemet depuis la zone dédié dans chaque test permettant de faire passer la fonction du rouge au vert.
Pour cela, vous devez utiliser correctement le mot-clé this, les closures et les fonctions call(), apply() et bind() dans les appels.
**Attention, certaines fonctions doivent être modifier pour que le test passe**

---

## Bonus

5. Une fois que tout vos tests sont au vert, refactorisez votre code pour l'améliorer tout en gardant vos tests au vert.
