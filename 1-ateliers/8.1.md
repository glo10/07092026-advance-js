# Atelier 8.1 : tests

## Enoncé

1. Créez un nouveau projet avec NPM et préparez l'environnement des tests en installant les dépendances en développement Vitest, Cypress et TypeScript.

2. Récupérez les [ressources dédiées de l'atelier 8.1](./resources/8.1/)

3. Copiez les fichiers présentes dans les ressources dans votre projet et modifier le package.json pour ajouter la commande
```json
"scripts": {
  "serve" : "node server.ts"
}
```

4. Lancez la commande `npm run serve` pour lancer l'application Node.

5. Ecrivez les tests depuis `tests/cart.test.ts` permettant de tester toutes les scénarios des fonctions de la classe Cart *src/cart.ts* depuis les .

6. Rédigez les tests *tests/api/user.ts* et *tests/utils/format.ts* en simulant les appels APIs externes avec les mocks.
Pour cela utilisez `vi.mock` pour intercepter le module `./api/user`.

7. Créez un fichier de test End-to-End `cypress/app/login.cy.ts` avec **Cypress** pour tester le parcours client suivant : 
- Le client navigue vers la page `/login`
- Le client remplit le champ `input[name="email"]` avec `"customer@test.com"`.
- Le client rempliy le champ `input[name="password"]` avec `"Secret123!"`.
- Le client clique sur le bouton de soumission `button[type="submit"]`
- La page actuelle contient un élément html "<h1>Bienvenue</h1>" lorsque les identifiants correspondent.
- La page actuelle indique le message "Veuillez réessayer" lorsque les identifiants ne correspondent pas.
