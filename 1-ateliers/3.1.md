## Bonus

4. Ecrivez une fonction ***loadLibrary()*** permettant de charger une librairie à partir de son URL et d'une callback qui doit afficher que la librairie a bien été chargée dans la console et utilisable depuis la console du navigateur.
Cette fonction doit créer un élément html ***&lt;script&gt;*** avec l'attribut ***src=URL*** de la librairie et cet élément est ajouté dans le *DOM*.
Exemple de l'appel de la fonction ***loadLibrary()***
```js
loadScript("https://code.jquery.com/jquery-3.7.1.min.js", function() {
  // jQuery est disponible uniquement une fois le callback exécuté
  console.log("Version de jQuery chargée : " + window.jQuery.fn.jquery);
});
```
