# Atelier 5.1 : les packages et la transpilation

1. Créez un nouveau projet en utilisant NPM.
2. Avec le standard Commonjs, écrivez un module *myMaths* dans *src/modules/myMaths* permettant de réaliser les opérations mathématiques de base avec les méthodes :
- *sum()*
- *divide()*
- *minus()*
- *multiply()*
3. Utilisez les méthodes du module *myMaths* dans le fichier *src/main.js*
4. Installez le package *babel* en environnement de développement uniquement
5. Dans le ***package.json***, ajoutez le script **`node src/main.js`** permettant de lancer votre programme **src/main.js**
6. Ajoutez un autre script permettant de lancer la compilation **`babel src -d dist`**
7. Installez ou ajoutez les presets de Babel **`@babel/core`** et **`@babel/preset-env`**
8. Créez le fichier de configuration **`babel.config.json`** (ou **`.babelrc`**) pour un projet ES2015+.

## Bonus

9. Configurez le preset **`@babel/preset-env`** en lui passant des options pour cibler uniquement les navigateurs occupant plus de `0.25%` des parts de marché et exclure les navigateurs abandonnés.
