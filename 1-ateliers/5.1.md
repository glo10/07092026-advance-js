# Atelier 5.1 : les packages et la transpilation

1. Créez un nouveau projet en utilisant NPM.

2. Avec le standard Commonjs, écrivez un module *myMaths* dans *src/modules/myMaths* permettant de réaliser les opérations mathématiques de base avec les méthodes :
- *sum()*
- *divide()*
- *minus()*
- *multiply()*

3. Utilisez les méthodes du module *myMaths* dans le fichier *src/main.js*

4. Installez les packages *@babel/core* et  *@babel/cli* en environnement de développement uniquement

5. Dans le ***package.json***, ajoutez dans la partie *scripts*  **`"start": "node src/main.js"`** permettant de lancer votre programme **src/main.js** et ajoutez la clé ***"type": "commonjs*** dans le package.json pour indiquer que votre module est de type ***commonjs***

6. Ajoutez un autre script dans la partie scripts du *package.json* pour lancer la transpilation **`"build": "babel src -d dist"`**

7. Installez le preset **`@babel/preset-env`**

8. Créez le fichier de configuration **`babel.config.json`** (ou **`.babelrc`**) et ajoutez `"presets": ["@babel/preset-env"]`
