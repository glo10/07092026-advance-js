# Atelier 7.1 : Web APIs et PWA

1. Récupérez les [ressources de l'atelier 7.1](./resources/7.1/), à la soumission du formulaire, enregistrez le choix du thème dans le **`localStorage`** et le jeton d'accès dans le **`sessionStorage`**.

2. Écrivez une fonction `loadPreferences()` qui s'exécute au chargement de la page pour réinjecter le thème et le jeton s'ils existent dans leurs storages respectifs.

3. Écrivez une fonction `fetchUserData(userId)` qui interroge l'API public [https://jsonplaceholder.typicode.com/users/${userid}](https://jsonplaceholder.typicode.com/users)

4. Avant de lancer la requête réseau avec `fetch`, vérifie si une réponse existe déjà dans le cache nommé `"user-data-v1"` via `caches.match()`.

5. Si la donnée est en cache, retourne-la directement. Sinon, exécute le `fetch`, clone la réponse (`response.clone()`), enregistre-la dans le cache avec `cache.put()`, puis retourne les données JSON.Z

6. Écrivez une fonction `getUserCoordinates()` qui retourne une `Promise` résolue avec les coordonnées `{ latitude, longitude }` obtenues via `navigator.geolocation.getCurrentPosition()`.

7. Gèrez proprement le rejet de la promesse en capturant les erreurs courantes (`PERMISSION_DENIED`, `POSITION_UNAVAILABLE`, `TIMEOUT`).

## Bonus 

8. Calculez la distance séparant l'utilisateur d'un point fixe (ex: Paris : 48.8566, 2.3522) et affiche le résultat en kilomètres dans le DOM.

9. Depuis le fichier `cache-worker.js`, écrivez la phase d'installation (`self.addEventListener('install', ...)`) qui met en cache le tableau `ASSETS_TO_CACHE`.

10. Ajoutez le gestionnaire d'événement `'fetch'` qui intercepte chaque requête et tente d'y répondre depuis le cache avant de solliciter le réseau.

11. Dans votre fichier principal `app.js`, écris le code d'enregistrement du Service Worker (`navigator.serviceWorker.register('./cache-worker.js')`) sous réserve que le navigateur supporte les Service Workers.
