# Atelier 6.1 : TypeScript

1. Créez un nouveau projet NPM

2. Installez TypeScript en tant que dépendance de développement

3. Créez le fichier de configuration de TypeScript ***tsconfig.json*** à l'aide de la commande
```bash
npx tsc --init
```

4. Ajoutez ou modifiez la configuration pour avoir 
```json
{
  "target": "ES2025",
  "strict": true
}  
```

5. Typez les fonctions présentes dans les [ressources 6.1](./resources/6.1/) en créant à chaque fois un fichier dédié aux types. Par exemple, le fichier ***src/user.ts*** importe le type ***types/user.d.ts***.

6. Appelez vos fonctions pour vérifier que les fonctionnent correctement.

7. Créez une interface ***PaymentInterface*** dont les caractéristiques sont : 
- `amount` (`number`)
- `currency` (`"EUR" | "USD"| "Yuan"|"GBP"`)
- `description` (optionnelle)

8. Créez une interface `CreditCardPaymentInterface` qui étend (`extends`) `PaymentInterface` et ajoute :
- `cardNumber` (`string`)
- `cvv` (`number`)

9. Ecrivez un alias de type pour la fonction `PaymentProcessor` qui prend en paramètre : 
- `PaymentInterface`
- Retourne un objet `{ success: boolean; transactionId?: string; error?: string }`

10. Implémentez la fonction `processCreditCard` qui respecte le type `PaymentProcessor`.

## Bonus

11. Créez une classe `BankAccount` dont les caractéristiques sont :
- Un constructeur avec la notation  **raccourci** pour les propriétés
  - `accountNumber` : *string*, accessible en lecture seule `readonly` depuis l'extérieur
  - `owner` : *string* et public
  - `balance` : *number*, privé `private`, avec une valeur par défaut *0*

12. Ajoutez une méthode `deposit(amount: number): void` qui augmente le solde si `amount > 0`.

13. Ajoutez une méthode `withdraw(amount: number): boolean` qui déduit le montant si les fonds sont suffisants et retourne un booléen.

14. Ajoutez un getter `currentBalance` pour consulter le solde sans permettre sa modification directe.

15. Créez une interface générique `ApiResponse<T>` décrivant une réponse d'API :
- `status`: `"success" | "error"`
- `data`: de type `T` (si `status === "success"`)
- `errorMessage`?: `string`

16. Écrivez une fonction générique `wrapInApiResponse<T>(data: T): ApiResponse<T>` qui prend n'importe quelle donnée et la renvoie encapsulée dans une réponse au statut `"success"`.
17. Écrivez une classe générique `DataStorage<T>` qui possède :
- Un tableau privé `items: T[]`.
- Une méthode `addItem(item: T): void`.
- Une méthode `getItem(index: number): T | undefined`.
- Une méthode `getAll(): readonly T[]`.


18. Instanciez un `DataStorage<User>` en réutilisant le type `User` de la question 6 et vérifiez que TypeScript bloque l'ajout d'une simple chaîne de caractères dans ce stockage.
