# Atelier 10.1 : Node.js et autres Web APIs

1. Créez un serveur Web qui sert une page index.html, une page 404.html et des ressources en JSON selon les critères suivants :
- Lorsque la route est / avec la méthode GET, le serveur rend la page index.html avec le code HTTP 200
- Lorsque l'utilisateur demande la route /api avec la méthode GET, le serveur renvoie le code HTTP 200 et les données en JSON par exemple :
```json
{
    "success": true,
    "status": 200,
    "data" : [
        { "id": 1, "description": "", "category": ""},
        { "id": 2, "description": "", "category": ""},
        { "id": 3, "description": "", "category": ""},
    ],
    "errors": []
}
```
- En dehors des routes / et /api, renvoyez la page 404.html avec le statut HTTP 404
